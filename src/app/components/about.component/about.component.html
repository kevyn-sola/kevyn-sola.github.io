À propos

Ingénieur logiciel full stack basé en Bretagne, issu d'une reconversion professionnelle après une carrière dans l'ingénierie du son.

Aujourd'hui chez Kalisport, je pilote le développement de plusieurs applications mobiles (Kalisport, FCGM Champion's League, Mark by @Kalisport), en Angular / TypeScript, pour +300 000 sportifs. Je conçois les APIs REST qui centralisent les données issues de multiples fédérations françaises, et contribue à l'évolution d'un framework interne en PHP.

Je développe en parallèle des projets personnels sur Java Spring Boot et NestJS, parce que monter en compétence passe d'abord par le code.
