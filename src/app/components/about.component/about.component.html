À propos

Développeur Full Stack basé en Bretagne, issu d'une reconversion professionnelle après une carrière dans l'ingénierie du son. Une transition qui m'a appris à comprendre un système dans son ensemble avant d'en optimiser une partie.

Aujourd'hui chez Kalisport, je pilote le développement de plusieurs applications mobiles (Kalisport, FCGM Champion's League, Mark by @Kalisport), en Angular / TypeScript, pour +300 000 sportifs. Je conçois en PHP les APIs REST qui centralisent les données issues de multiples fédérations françaises, et contribue à l'évolution d'un framework interne dont l'architecture s'inspire des principes d'un conteneur IoC Spring.

Je développe en parallèle des projets personnels sur Java Spring Boot, parce que monter en compétence passe d'abord par le code.
